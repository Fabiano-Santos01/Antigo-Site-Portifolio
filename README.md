# Antigo Site Portifólio

Meu primeiro site portfólio, publicado como site estático pelo GitHub Pages.

## Publicação

No repositório, acesse **Settings > Pages** e configure **Deploy from a branch**, branch `main` e pasta `/(root)`.

O site estático usa `index.html` como página inicial. Os recursos que dependem do backend Flask não estão disponíveis no GitHub Pages.
